# LUKFLIX

Site de filmes e séries com temática Netflix: catálogo escuro em vermelho/preto com grid de pôsteres, busca instantânea e filtros por categoria. Feito em HTML, CSS e JavaScript puro — sem frameworks e sem build.

## Recursos

- Catálogo responsivo (grid adaptável a desktop e mobile)
- Busca por título em tempo real
- Filtros por categoria/filmes/séries
- Tema dark inspirado na Netflix
- Font Awesome via CDN

## Como usar

Abra `index.html` direto no navegador ou publique em qualquer hospedagem estática:

```bash
npx serve .
# ou GitHub Pages / Netlify / Vercel
```

## Estrutura

| Arquivo | Função |
|---|---|
| `index.html` | Aplicação principal (catálogo) |
| `alter1.html` / `alter2.html` | Variações alternativas do layout |
| `main0.html` | Protótipo inicial |
